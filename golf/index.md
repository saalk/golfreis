# Golf

Overzicht van relevante golfregio's en banen voor de villa-vergelijking.

## Per golfbaan

We verzamelen:

- naam
- plaats / regio
- type baan
- 18 holes
- afstand vanaf villa
- rijtijd vanaf villa
- greenfee-indicatie
- huur buggy / trolley indien relevant
- website
- bron
- status

## Golfregio

Bij iedere villa beoordelen we niet alleen de dichtstbijzijnde baan, maar ook de totale golfkeuze binnen ongeveer 30–60 minuten rijden.
