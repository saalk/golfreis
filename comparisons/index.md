# Vergelijkingen

We vergelijken twee hoofdtypen golfvakanties:

1. **Zelf samengestelde villa-reis** — villa + vlucht + huurauto/transfer + golf zelf organiseren.
2. **Georganiseerde golfreis** — reisaanbieder met hotel, ontbijt, diner, 6x golf, vlucht en vervoer.

## Categorieën

| Categorie | Wat vergelijken we? |
|---|---|
| Accommodatie | Villa versus hotel |
| Kamers & privacy | Slaapkamers, badkamers, bezetting, privacy |
| Maaltijden | Ontbijt, diner, inbegrepen / niet inbegrepen |
| Vluchten | Vlucht, bagage, tijden, luchthaven |
| Transfers | Luchthaven ↔ accommodatie en vervoer naar golfbanen |
| Golf | Aantal rondes, banen, greenfees, tee times |
| Golfvervoer | Eigen huurauto versus georganiseerd vervoer |
| Vrijheid | Eigen programma versus vast programma |
| Prijs | Totaalprijs en prijs per persoon |
| Extra kosten | Niet inbegrepen onderdelen en toeslagen |
| Reisduur | Aantal nachten / dagen |
| Locatie | Ligging, omgeving en bereikbaarheid |
| Faciliteiten | Zwembad, spa, restaurant, bar, keuken etc. |
| Reisorganisatie | Contact, begeleiding, flexibiliteit |
| Risico & gemak | Zelf regelen versus één pakket |
| Annulering | Voorwaarden en flexibiliteit |
